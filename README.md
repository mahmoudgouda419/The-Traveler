# The Traveller
___

The Traveller is an AI-powered travel planning platform that can help you discover and create personalized travel trips based on your interests, budget, and country. Users can generate trips thier own trips, explore other users trips, and manage their travel plans through an easy interface, while administrators can monitor activity and manage users through a dedicated dashboard. Additionally and AI spcielized bot add to the website that you can ask about your next trip details.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Notes

* Users can sign in using their Google account and Github account.
* Only Admin users have access to the dashboard and management tools.
* Third-party cookies may be required for Google authentication.

# The Traveller

The Traveller is a web application that helps users generate personalized travel itineraries using AI.

## Features

* Google Authentication
* AI-generated travel plans
* Create and view trips
* Admin dashboard
* User management
* Trip statistics and analytics

## Built With

* React Router
* TypeScript
* Tailwind CSS
* Appwrite
* Google OAuth
* Syncfusion Components

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Notes

* Users can sign in using their Google account.
* Admin users have access to the dashboard and management tools.
* Third-party cookies may be required for Google authentication in some browsers.
